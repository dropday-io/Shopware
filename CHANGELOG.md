# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-XX

### Added
- Initial release
- Automatic order synchronization to Dropday.io
- Manual order sync from order detail page
- Configurable trigger states (Open, Paid, In Progress)
- Multi-language support (English, German)
- Sales channel specific configuration
- API connection testing
- Optional API logging for debugging
- Product image URL support
- Full order data mapping including:
  - Customer information
  - Shipping address
  - Shipping method details
  - Line items with EAN, SKU, and pricing
  - Manufacturer/brand information
